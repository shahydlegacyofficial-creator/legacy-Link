# Official requirements checked 8 November 2026

- Target API: new phone apps/updates must target API 36 under the current schedule. https://support.google.com/googleplay/android-developer/answer/11926878
- Listing fields: title 30, short description 80, full description 4,000 characters; new apps use Android App Bundles. https://support.google.com/googleplay/android-developer/answer/9859152
- Asset specifications: 512 × 512 store icon; 1024 × 500 feature graphic; phone screenshot rules and recommended 1080 × 1920 portrait format. https://support.google.com/googleplay/android-developer/answer/9866151
- User data and prominent disclosure: sensitive notification data needs transparent handling, appropriate consent and secure transport. https://support.google.com/googleplay/android-developer/answer/10144311 and https://support.google.com/googleplay/android-developer/answer/11150561
- Data safety definitions and publisher responsibility. https://support.google.com/googleplay/android-developer/answer/10787469
- Public HTML policy and app access requirements. https://support.google.com/googleplay/android-developer/answer/9859455
- Financial features declaration for all published apps. https://support.google.com/googleplay/android-developer/answer/13849271
- Newer personal-account testing requirements. https://support.google.com/googleplay/android-developer/answer/14151465
- Android restricted-settings steps. https://support.google.com/android/answer/12623953
- Notification-listener settings intent. https://developer.android.com/reference/android/provider/Settings#ACTION_NOTIFICATION_LISTENER_DETAIL_SETTINGS
- API 36 toolchain compatibility. https://developer.android.com/build/releases/agp-8-13-0-release-notes

The Console can change. Review the live requirements shown for your account before submitting. Product-specific statements in the policy, support material and listing are derived from the app source, not promises of approval by Google or a bank.
