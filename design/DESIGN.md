# Legacy Link 2.0

The Android companion connects selected notifications to the user's Legacy AI assistant. The overview answers three questions: is setup complete, is forwarding enabled, and is anything waiting to send?

- Graphite `#0B0E13`, surface `#141922`, raised surface `#1C232F`, platinum `#F1F4F8`, muted blue-grey `#A0ADC0`, and ice blue `#AECDF7`.
- Bundled Manrope for display, body and utility labels; licensed under the included SIL Open Font License.
- Native Android views, 24 dp page margins, rounded connection panels, and a persistent three-tab navigation.
- Original vector icon combines the supplied Legacy Studios wordmark's angular A with an L. The blue joining segment represents the link. Adaptive, monochrome and legacy density variants are included.
- Connection tests are described as the last test, never as continuous online monitoring. Counts and delivery timestamps come from local app state. No example transactions or financial data are displayed.
- Source apps are opt-in. Pairing secrets are hidden by default. Only the last delivery time is added; notification bodies are not copied into a new activity history.

The transport API, app identity (`mv.legacy.link`), supported Android versions (8.0+), notification listener, retry queue, and private-by-default source selection remain compatible with the original app.
